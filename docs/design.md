# Product & UI Design Rules

## Product goal

Help Philippine SMEs understand and improve local search visibility without requiring an SEO specialist.

## Primary navigation

- Overview
- Businesses
- Local Visibility
- Keywords
- Website Audit
- Reviews
- Competitors
- Recommendations
- Reports
- Integrations
- Settings

## Dashboard hierarchy

Top:
- business/location selector
- Local SEO score
- trend indicators

Middle:
- highest-impact opportunities
- visibility trend
- review sentiment
- technical issues

Bottom:
- recent automation runs
- completed actions
- data freshness

## Recommendation card

Every recommendation should display:
- category
- title
- evidence
- impact
- confidence
- recommended action
- status
- last updated

Never show an AI recommendation without evidence.

## Philippine localization

Support:
- PHP currency where relevant
- Asia/Manila timezone
- Philippine region/province/city/municipality hierarchy
- English, Filipino, and Taglish review text
- mobile-first layouts

## UX principles

- Progressive disclosure
- Clear status indicators
- No misleading SEO guarantees
- Explain why a score changed
- Always display data freshness
- Never imply Google ranking guarantees
- Avoid dark patterns
- Destructive/external actions require confirmation

## Accessibility

Target WCAG 2.2 AA where practical:
- keyboard navigation
- semantic HTML
- visible focus
- sufficient contrast
- form labels
- error messages
- reduced motion support
